## ✦ Overview

A premium, editorial-style personal portfolio built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies. Designed to function as a professional product showcase with interactive technical components.

---

## ✦ Features

| Feature | Description |
|---|---|
| 🎬 **Dual-Split Hero** | Full-viewport split layout with animated portrait and social strip |
| 📖 **Blog Section** | 3 static technical articles with a dedicated full-screen reader page |
| 🧠 **Project Drawer** | Sliding spec panel with architecture details for each project |
| ⌨️ **Cmd+K Menu** | Global command palette for keyboard-first site navigation |
| 🕐 **Loading Screen** | Branded "Sondhiya" entrance overlay with content blur effect |
| 🏗️ **Stack Inspector** | Interactive tech stack hover inspector with telemetry details |
| 📅 **Timeline** | Engineering milestones and build log history |
| 🎥 **Gallery Carousel** | Cinematic widescreen photo carousel with auto-advance |
| 📨 **Contact Form** | Animated terminal-style contact form with copy email tool |
| 📱 **Responsive Design** | Fully responsive across mobile, tablet, and desktop |
| 🍔 **Mobile Navigation** | Hamburger toggle with animated menu drawer |

## ✦ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom animations, glassmorphism, CSS variables

- **Google Fonts** — Inter, Dancing Script, JetBrains Mono
